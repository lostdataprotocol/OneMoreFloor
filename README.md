# One More Floor

A roguelike dungeon crawler for the M5Cardputer.

One More Floor is a floor-based dungeon crawler built for M5Stack devices. The game includes procedural dungeon runs, turn-based combat, bosses, shops, crafting, gathering, upgrades, contracts, lore entries, autosave support, and more.

## V1.1 Update

V1.1 focuses on UI cleanup, general polish, and a new experimental companion build for the M5Stack Cardputer ADV and M5Stack Core2.

### V1.1 Changes

- UI fixes and layout cleanup
- Improved menu readability
- Better navigation in several screens
- General polish after the V1 release
- New ADV + Core2 companion build
- ESP-NOW communication between devices
- Two-device controller/screen gameplay setup

## Main Game Features

- Procedural floor-based dungeon runs
- Turn-based combat system
- Multiple enemy types and bosses
- Mandatory mini-boss floors
- Elite enemies with rare rewards
- Soul Ash progression system
- Gold, shops, and rotating shop stock
- Crafting and gear upgrading
- Resource gathering: mining, woodcutting, herblore, and more
- Permanent tools like pickaxe and axe
- Upgradeable gathering tools
- Potions: HP, MP, ATK, and DEF boosts
- Enemy item drops such as potions, lockpicks, bombs, and resources
- Contracts / quests system
- Secret world events
- Map / minimap screen
- Bestiary and lore entries
- Combat log history
- Autosave safety improvements
- Save data stored in its own game folder
- Improved UI and title screen

## Companion Build

V1.1 includes an experimental companion build for the M5Stack Cardputer ADV and M5Stack Core2.

In this setup:

- M5Stack Cardputer ADV = controller
- M5Stack Core2 = screen
- Communication is handled through ESP-NOW

This allows One More Floor to run as a two-device setup, with input handled on the ADV and the game displayed on the Core2.
